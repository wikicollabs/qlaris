# Qlaris

Qlaris is a tool for contributing to Wikidata.

## Development

Qlaris uses Vue 3, TypeScript, and Wikimedia Codex for the frontend, and Node.js, TypeScript, and Express for the backend.

The project uses pnpm workspaces.
